# SD Pipeline-2021-02 series — revision history appendix

Tracking the series' drift from its original prescriptive form to the current
performance-based structure this crosswalk targets. Compiled from TSA's own
publications and the secondary sources cited in `docs/BUILD_SPEC.md`; not a
substitute for reading the primary text.

| Version | Effective | Superseded | Character | What changed |
|---|---|---|---|---|
| SD Pipeline-2021-01 | 2021-05 | — | Prescriptive | Initial post-Colonial-Pipeline directive: named a cybersecurity coordinator, required incident reporting to CISA. |
| SD Pipeline-2021-02 | 2021-07 | 2021-02B | Prescriptive | First directive requiring specific technical measures (segmentation, MFA/compensating controls, patching) on a fixed timeline; widely reported as operationally difficult for OT environments. |
| SD Pipeline-2021-02B | 2022-06-09 | 2021-02C | Prescriptive (interim) | Retained as the "Attachment" interim-measures baseline referenced by 02C until an operator's Cybersecurity Implementation Plan (CIP) is TSA-approved. |
| **SD Pipeline-2021-02C** | 2022-07-27 | 2021-02D | **Performance-based** | The pivot this crosswalk is built on: introduced the CIP/CIRP/CAP structure (Sections III.A-G) in place of prescriptive technical mandates, letting operators choose *how* to meet outcomes TSA specifies. |
| SD Pipeline-2021-02D | 2023-07-27 | 2021-02E | Performance-based | Added: CAP must test ≥30% of implemented measures annually, 100% coverage over any 3-year period; removed the prior "alternative measures" safe-harbor; added 60-day TSA notification when Critical Cyber System status changes; CIRP exercises must test ≥2 response objectives annually with named-personnel participation. |
| SD Pipeline-2021-02E | ratified 2024-08-23 | 2021-02F | Performance-based | Per the Transportation Security Oversight Board's ratification notice: "new and modified definitions clarifying certain terms and harmonizing terminology" across TSA's pipeline and rail cybersecurity directives. No new substantive outcomes reported. |
| SD Pipeline-2021-02F | 2025-05-03 | current per tsa.gov/sd-and-ea as of 2026-09-09 | Performance-based (presumed) | **Full text not retrieved during this build — see `docs/LIMITATIONS.md` item 1.** Listed as the current version on TSA's own directive index; substance not independently confirmed here. |
| (any later letter, e.g. 02G) | unknown | — | unknown | Check tsa.gov/sd-and-ea for the current version before relying on this crosswalk. |

## Adjacent regulatory activity (context, not part of the crosswalk)

- **January 2025** — DHS/TSOB published a Federal Register notice ratifying
  SD Pipeline-2021-01D and SD Pipeline-2021-02E (the ratification requirement
  under 49 U.S.C. § 114(l)(2)(B) is procedural, not a public-comment
  rulemaking).
- **2025–2026** — TSA has run Paperwork Reduction Act information-collection
  comment periods (most recently a 30-day period with a comment deadline of
  2026-02-02) covering the *reporting/recordkeeping burden* of the existing
  SD Pipeline-2021-02 series requirements. This is **not** a Notice of
  Proposed Rulemaking and does not itself change the substantive
  requirements crosswalked here — but it is the closest thing to a public
  comment opportunity currently open on this program, and is worth watching
  if a public-comment venue becomes relevant to a later version of this
  project.
